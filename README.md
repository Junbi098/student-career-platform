
# Student Career Intelligence Platform

A platform designed to help students in Mauritius
discover career opportunities and identify companies
worth approaching for internships and junior roles.

## Current development phase

Proof of Concept (POC): Company Intelligence.

The first objective is to extract structured company
information from HTML sources.

## Technology Stack

- Java 21
- Maven
- jsoup 1.23.2
- JUnit 5

## Current Features

- Extract a company name from HTML
- Handle missing company names using Optional
- Automated unit tests

## Run Tests

Open the project in IntelliJ IDEA.

In the Maven tool window, execute:

    clean test

Expected result:

    BUILD SUCCESS

## Roadmap

- Company and source reference models
- HTML extraction and validation
- Company intelligence pipeline
- Spring Boot backend
